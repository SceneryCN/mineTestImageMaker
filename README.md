# JLImage

基于 [Agnes AI](https://agnes-ai.com/doc/overview) 的智能对话与生图 Web 应用。

## 功能

- **统一对话** — 聊天与生图同一入口，LLM 自动识别意图
- **流式输出** — 实时流式回复
- **智能生图** — 说「帮我画…」自动调用生图 API
- **图片修正** — 悬浮图片可编辑，附带当前图继续优化
- **本地 Key** — API Key 仅保存在浏览器

## 本地开发

```bash
npm install
npm run dev
```

## 部署

推送到 GitHub，`main` 分支自动部署到 GitHub Pages。
